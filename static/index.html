Convertidor de artículos

Convierte referencias comerciales a IDs internos y actualiza el catálogo maestro desde exportaciones de inventario.

Selecciona o arrastra un archivo Excel o CSV

Se aceptan .xlsx y .csv. El archivo original no se modifica. La salida es CSV/ZIP.

Reglas aplicadas

  1. Lee la referencia comercial desde ID INTERNO ARTICULO.
  2. Busca coincidencia exacta en el campo Ref del catálogo.
  3. Reemplaza por ID interno y completa NOMBRE DE ARTICULO.
  4. Si no hay coincidencia, conserva la fila y la reporta.
