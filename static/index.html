Procesamiento de inventario

Convertidor de artículos

Carga un archivo Excel o CSV. El sistema busca cada referencia en el catálogo interno, actualiza el ID y el nombre, y genera CSV (o ZIP si hay varias hojas).

Selecciona o arrastra un archivo Excel o CSV

Se aceptan .xlsx y .csv. El archivo original no se modifica. La salida es CSV/ZIP.

Reglas aplicadas

  1. Busca cada valor de ID INTERNO ARTICULO contra el catálogo interno (Ref).
  2. Reemplaza por ID interno y actualiza NOMBRE DE ARTICULO.
  3. Si una referencia no existe, la fila se conserva y se reporta.
  4. La pestaña Lista, si aparece en un Excel, se ignora y no modifica el catálogo.
